# 开发说明

## 模块职责

- `Content/Python/init_unreal.py`：在工程绑定检查通过后注册编辑器菜单。
- `retarget_assistant/core.py`：纯标准库骨架分析、骨骼角色匹配与链建议，可脱离 UE 测试。
- `retarget_assistant/unreal_adapter.py`：读取 UE 资源、校验工程边界、建立 IK 资源、导出及采样检查。
- `retarget_assistant/menu.py`：编辑器选择、会话、提示和操作入口。
- `tools/configure_project.py`：为已安装插件的工程创建绑定 JSON，不修改 `.uproject`。
- `tests/`：结构诊断、写入边界和配置工具的自动化测试。

目录名是 `Content/Python/retarget_assistant`；修改代码时保持入口与包结构一致。`require_sandbox()` 为历史函数名，0.2 起同时支持独立工程与明确授权的项目模式。

## 检查范围

单元测试使用合成骨架与假的 UE 接口，不运行编辑器。测试覆盖错误层级、关键骨骼缺失、名称歧义、工程授权、路径越界和源动画骨架匹配等问题。

编辑器回归需要自行准备有权使用的角色及动画，逐项验证：

1. 首次启动时菜单可用，重新注册不会重复添加入口。
2. 未绑定、路径不匹配或非布尔授权的工程拒绝操作。
3. 源、目标角色和所选动画被正确识别。
4. 新建的 IK Rig、IK Retargeter 和动画仅位于本次生成目录。
5. 导出后保存并重新启动编辑器，检查轨道、骨架、时长和实际预览。
6. 逐段检查脚接触、手臂姿势、比例、Root Motion 与玩法表现。

本仓库不提供真实工程、角色、动画、原始运行日志或个人机器的安装记录。添加验证证据时使用合成数据或有权公开的素材，并先脱敏。

## 常见问题

**没有看到菜单：**确认插件与依赖已启用、已重启编辑器，并检查当前工程 `Config/RetargetAssistantProject.json` 是否绑定实际 `.uproject`。在 Output Log 搜索 `RetargetAssistant` 查看拒绝原因。工程移动后旧路径会失效。

**提示 Sandbox policy does not match：**旧版独立工程启动器可能使用了其他路径的沙箱配置。本公开版不包含与某台机器绑定的启动器。按 README 直接安装并配置当前工程，避免复制旧授权文件。

**动画骨架不匹配：**所选 Animation Sequence 必须直接绑定源角色的 Skeleton。名字相似或显示兼容不代表绑定相同。

**结构检查通过但效果不好：**结构检查不能证明姿势或接触正确。先打开新建的 IK Retargeter，检查姿势、比例与链设置，每次只改一个因素并重新预览。

**导出中途失败：**已经创建的本次资源可能保留，工具没有事务式回滚。检查日志和本次生成目录，确认后自行清理失败批次，再重新建立或导出。

## 贡献建议

修复时尽量把规则放在核心层，把 UE 资源操作留在适配层。不要通过放宽输出目录或覆盖源动画绕过失败。UI 文案应区分静态检查、动画数据检查和实际视觉验证。

仓库 CI 仅运行标准库测试，UE 回归结果请单独说明引擎版本、样本、复现步骤和未检查项目。
