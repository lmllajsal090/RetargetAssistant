Control Rig 验证包含两个手部目标、两个肘部控制器、两个独立权重控制器，九个图节点和八条实际连接。保存后用新进程重新加载并执行 VM，移动目标后手腕抵达目标；改变肘部提示会改变肘部而保留手部目标；零权重停止对应手臂求解。根、骨盆和双腿的变换在这些检查中保持不变。

参数校准在一个原生 AnimInstance 派生的测试动画蓝图上执行。检查正式源图不变、只修改新副本、拒绝过期 expected 值、拒绝恢复冲突，以及恢复目标引脚时保留另一个后续参数修改。

本轮还核对 70 个输入资产、游戏源码及工程文件的哈希没有变化。该数量仅描述本地样例，不能推广为任意项目均不会产生其他变化的证明。

## 在自己的工程中复现

1. 用自己的资源副本安装插件并配置工程绑定。
2. 运行原重定向流程，保存并重新启动编辑器，检查导出动画。
3. 检查实际动画蓝图，制造再修正零权重、Ignore 平移和旋转空间不匹配，核对报告。
4. 给测试武器设置独立握点；核对正确组件，测试缺失握点与重名组件的处理，再在 PIE 中采样玩家。
5. 导出校准配置，生成副本，核对源图与原资产不变。修改同一引脚后尝试恢复，应被冲突检查拒绝；再验证无关修改可保留。
6. 生成双臂 Control Rig，重开工程后移动双手和肘部控制器，测试左右权重，并对照根与腿部。
7. 使用真实持枪动画，逐项检查正面、侧面、移动、瞄准、跳跃和换弹。保存自己的截图与结果。

## 没有宣称通过的项目

- 正式游戏的完整 PIE / 网络 / 打包验收。
- 手指握合、脚接触、滑步与自然度的自动判断。
- 网格逐三角形穿模检测或自动避障。
- 所有人形比例、所有命名方式和其他 UE 版本的兼容性。

静态参数、单帧接触、编译和 VM 执行分别提供不同证据，不能相互替代。CI 只运行仓库内的标准库测试。
